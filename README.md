## 🧭 강연 핵심 철학 & 강사의 포지션

> **"프롬프트 작성을 넘어, 안전하고 검증된 실무 에이전트 하네스(Harness) 시스템으로"**

본 강연은 시시한 프롬프트 기교를 가르치지 않습니다.  
말(프롬프트)로 때우는 일회성 채팅을 종식시키고, 프로 엔지니어들이 현업에서 실제로 사용하는 **7대 실전 에이전틱 하네스(Harness) 시스템**을 전수합니다.

---

## 🛠️ 실무 에이전트 통제의 7대 핵심 하네스 기법

1. **폴더 구조 (Folder Architecture)**: 가장 완벽한 질서. rules, references, input, output 4대 표준 디렉토리로 경로 이탈 80% 차단
2. **레퍼런스 (Concrete References)**: 단 한 장의 확신. 주관적 형용사 대신 과거 실제로 결재 통과된 양질의 문서 1장 주입
3. **CLAUDE.md (Context Pinning)**: 영구히 각인된 원칙. 부서 대원칙, 전결선, 금기 어휘를 단 하나의 시스템 파일로 고정
4. **Metric의 중요성 (Acceptance Criteria)**: 합격의 절대 기준. 기안 작성 전 3대 정량 합격 채점표(누락 0건, 오차 0%, 규정 준수 100%) 사전 확립
5. **자가 치유 루프 (Autonomous Self-Healing)**: 스스로 도달하는 무결점. 채점표를 대조하며 100점이 될 때까지 스스로 수정·재시도하는 자율 루프
6. **멀티에이전트 팀 (Multi-Agent Teaming)**: 분업의 절대적 힘. [조사관 - 기안자 - 품질감독관] 3인 1조 분업 가동
7. **적대적 검증 (Adversarial Verification / Red Teaming)**: 가장 가혹한 필터. 감사관 페르소나를 부여해 결재 전 결점 난타 및 자가 방어

  05. 강의 아젠다: 프롬프트를 넘어, 실무 에이전트 하네스로. (1부/2부/3부 로드맵)

[PART 1 · 진짜 AI 병목과 도메인 지식]
  06. 취합의 현실: 취합의 지옥. 매일 쏟아지는 수십 건의 데이터.

  09. 병목 ③ 환각의 공포: 날조된 사규 조항. 100% 감사 지적의 공포.
  10. 핵심 명제 ①: AI는 문장 기계. 조직을 지키는 것은 도메인 지식.
  11. 병목 비주얼 [그림]: 진짜 병목. 머릿속에 갇힌 암묵지.
  12. 1부 결론: 프롬프트 대신, 무엇으로 일하게 할 것인가.

[PART 2 · 프롬프트 없는 세상: 7대 실전 에이전틱 하네스]
  13. 2부 전환 (히어로): 7대 실전 하네스. 에이전트를 통제하는 절대 원칙.
  14. 7대 기법 로드맵: 프롬프트 없는 세상. 시스템으로 일하는 7가지 방법.
  15. 기법 ① 폴더 구조 [그림]: 폴더 구조. 가장 완벽한 질서.
  16. 표준 폴더 아키텍처: 4대 표준 디렉토리. rules · references · input · output.
  17. 기법 ② 레퍼런스: 레퍼런스. 단 한 장의 확신.
  18. 레퍼런스 비교: 말로 시키기 vs 레퍼런스 던지기.
  19. 기법 ③ CLAUDE.md: CLAUDE.md. 영구히 각인된 원칙.
  20. CLAUDE.md 실물: CLAUDE.md 실물 예시. 팀원 누구나 공유하는 단 하나의 기준.
  21. 기법 ④ Metric [그림]: Metric의 중요성. 합격의 절대 기준.
  22. 3대 무결점 지표: 3대 무결점 지표. 누락 0건 · 오차 0% · 사규 준수 100%.
  23. 기법 ⑤ 자율 루프 [그림]: 자가 치유 루프. 스스로 도달하는 무결점.
  24. 루프 매커니즘: 자율 루프의 4단계. 생성에서 치유까지.
  25. 기법 ⑥ 멀티에이전트 [그림]: 멀티에이전트 팀. 분업의 절대적 힘.
  26. 3인 1조 분업: 3인 1조 에이전트 분업. 조사관 · 기안자 · 품질감독관.
  27. 기법 ⑦ 적대적 검증 [그림]: 적대적 검증. 가장 가혹한 필터.
  28. 적대적 검증 3단계: 레드팀 감사관의 3단계 공격. 사규 위반 · 수치 불일치 · 무결점 방어.
  29. 7대 기법 총괄: 프롬프트 제로. 오직 시스템(Harness)만으로.

[PART 3 · 실전 환경과 공기업 적용]
  30. 식당 vs 주방 [그림]: 식당 vs 주방. 외부 SaaS를 넘어 사내 주방으로.
  31. 브라우저 제어 [그림]: 브라우저 제어. 사내 전산망의 자동 연결.

  36. 실무 일치 [그림]: 실무의 본질. 우리가 원래 일하던 방식 그대로.

  39. 우선 구축 스킬 3선: 우선 구축 스킬 3선. 주간보고 · 민원 · 규정대조.

  41. 실천 다짐: 이번 주에 우리 부서에서 가장 먼저 폴더와 레퍼런스를 갖추고 싶은 업무는?
  42. 현업 복귀 과제: 현업 복귀 실천 과제. 레퍼런스 · CLAUDE.md · 적대적 검증.
