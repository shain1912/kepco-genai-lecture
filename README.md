## 🛠️ PART 3 활용 사례 7대 유형 & 한전 적용 지점

1. **문서형 (읽고 쓰는 일을 통째로 위임)**: 수백 페이지 송배전 기술기준 개정 전후 신구조문대조표 및 조항별 실무 영향도 평가 자동 작성
2. **데이터형 (엑셀 함수 없이 분석까지)**: 사업소별 민원·고장 접수 비정형 텍스트 자동 분류 및 취약 설비·계절별 고장 패턴 추이 분석
3. **검색형 RAG (우리 자료에만 근거해 답하게)**: 과거 10년간 설비 사고·고장 사례 유사도 검색을 통한 원인 추정 및 긴급 복구 매뉴얼 자동 호출
4. **비전형 (눈으로 보던 시각적 점검을 자동화)**: 드론 촬영 영상을 통한 송전 철탑 애자 결함·부식 스캐닝 및 작업장 안전장구 실시간 모니터링
5. **엣지·현장형 (네트워크 없는 현장에서도)**: 해군 교육사령부 × 부산대 TinyML 음향 이상감지 기술을 변전실 변압기·회전기기 예지정비로 대입 (오프라인 즉시 판정)
6. **자동화형 (AI가 화면을 직접 조작)**: Computer Use 브라우저 제어로 사내 레거시 전산망 반복 조회, ERP 데이터 자동 입력 및 보고서 배포
7. **제작형 (콘텐츠를 찍어낸다)**: EduGen AI 개발 경험을 토대로 신입사원 부서별 직무 온보딩 자료 자동 변형 및 대민 정전 안내문 시각자료 양산

## 📋 슬라이드 구성 (총 34장, 120분 표준 호흡)

```
[여는 이야기: 판이 바뀌었다 (0:00–0:15 / 15분)]
  01. 표지 (히어로): 생성형 AI 시대의 일하는 법 (부제: 프롬프트의 시대는 끝났다. 남는 것은 도메인 지식이다)
  02. 청중 진단: 지금 쓰고 계신 도구와 가장 답답했던 막힌 지점
  03. 라이브 데모 ① [그림]: 말 한 마디로 끝나는 일 (공개 자료 5건 → 비교 분석 + 도표 + 보고서 초안)
  04. 2시간의 프레임: "AI를 배운다"가 아니라 "일하는 방식을 바꾼다"

[PART 1 · 프롬프트의 시대는 끝났다 (0:15–0:40 / 25분)]
  05. PART 1 전환 (히어로): 프롬프트의 시대는 끝났다 (1세대 ➔ 2세대 ➔ 3세대 하네스)
  06. 3세대의 진화: 1세대 프롬프트 ➔ 2세대 컨텍스트 ➔ 3세대 하네스 엔지니어링
  07. 왜 끝났나: 모델이 알아서 한다. 병목은 이제 자료와 검증으로 이동
  08. 컨텍스트 4대 요소: 컨텍스트 = 자료 + 규칙 + 도구 + 검증 루프 (작업 환경 설계)
  09. 대조 데모: 같은 요청, 컨텍스트 유무에 따른 결과의 극적 격차
  10. 바이브코딩 [그림]: 바이브코딩이란 무엇인가 (만드는 사람이 아닌, 시키고 검수하는 사람)

[PART 2 · 도메인 지식이 진짜 자산이다 (0:40–1:10 / 30분)]
  11. PART 2 전환 (히어로): 도메인 지식이 진짜 자산이다 (일반해를 넘어 특수해로)
  12. 일반해 vs 특수해: 모델이 주는 건 일반해, 여러분이 가진 건 특수해
  13. 프로젝트 사례 ① [그림]: 부산디자인진흥원 공공디자인 진단 (전문가 기준 시스템화)
  14. 프로젝트 사례 ②: 제조 기업 프라이빗 AI (데이터 규칙 · PII 마스킹 · 스마트 라우팅)
  15. 프로젝트 사례 ③ [그림]: 엔지니어링 도면 검색 멀티모달 RAG (도면을 아는 사람만 설계 가능)
  16. 한전의 해자: 한전 임직원 여러분만이 가진 대체 불가능한 3대 해자 (계통 운영 · 설비 이력 · 사규 관행)
  17. 즉석 활동: 'AI가 절대 못 하는 우리 일' 3가지 적기 ➔ 부서의 진짜 자산 목록

[휴식 (1:10–1:20 / 10분)]
  18. 휴식: 잠시 쉬어가겠습니다 (개별 질의응답 및 후반부 시연 소재 접수)

[PART 3 · 활용 사례 퍼레이드 — 7가지 유형 (1:20–1:50 / 30분)]
  19. PART 3 전환 (히어로): 활용 사례 퍼레이드 — 7가지 실무 유형과 한전 적용 지점
  20. 7대 유형 로드맵: 문서형 · 데이터형 · 검색형 · 비전형 · 엣지형 · 자동화형 · 제작형
  21. 유형 1: 문서형: 읽고 쓰는 일을 통째로 위임 ➔ 송배전 기술기준 신구대조표
  22. 유형 2: 데이터형: 엑셀 함수 없이 분석까지 ➔ 민원·고장 접수 비정형 텍스트 자동 분류
  23. 유형 3: 검색형 RAG [그림]: 우리 자료에만 근거해 답하게 ➔ 설비 사고·고장 유사도 검색
  24. 유형 4: 비전형: 눈으로 보던 일을 자동화 ➔ 철탑 애자 결함 및 부식 드론 탐지
  25. 유형 5: 엣지·현장형 [그림]: 해군 교육사령부 TinyML 음향 이상감지 ➔ 한전 변압기 예지정비 대입
  26. 유형 6: 자동화형 [그림]: Computer Use 브라우저 조작 및 Orca ADE 에이전트 병렬 배치
  27. 유형 7: 제작형: EduGen AI 개발 경험 ➔ 직무별 온보딩 교안 및 정전 안내문 양산
  28. 7대 유형 매트릭스: 난이도 vs 업무 파급력에 따른 3단계 도입 우선순위

[닫는 이야기: 무엇부터 할 것인가 (1:50–2:00 / 10분)]
  29. 닫는 이야기 전환 (히어로): 무엇부터 할 것인가 (업무 자산화 3단계 시작 순서)
  30. 업무 자산화 3단계: 가장 잘 아는 업무 1건 ➔ 컨텍스트 문서화 ➔ 검증 루프 결합
  31. 공기업 보안 3원칙: 비식별화 필수 · 폐쇄망 및 엣지 처리 · 인간 최종 검수 책임
  32. 3단 검증 체크리스트: 1단 데이터 정합성 · 2단 규정 적합성 · 3단 감사 리스크 필터
  33. 심화 2일 과정 안내 [그림]: 내 손으로 구축하는 사내 에이전트 및 바이브코딩 실무
  34. 마무리 & Q&A (히어로): "프롬프트의 시대는 끝났다. 남는 것은 도메인 지식이다"
```
