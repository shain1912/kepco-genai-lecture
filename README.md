### 🛠️ PART 3 활용 사례 7대 실무 & 내일부터 바로 쓰는 방법

1. **HWP(한글) 수정하기 & docx 보고서 만들기**: 거친 회의 메모만 주면 우리 부서 표준 양식 그대로 개요, 현황, 조치계획까지 맞춤 작성
2. **엑셀 정리하기 & 수치 집계 자동화**: "부서별 엑셀 5개 합치고 이상치 찾아줘" 말 한마디로 함수 없이 취합·정제 완료
3. **규정집 찾기 & 시장·타사 자료조사 시키기**: 수백 페이지 사규에서 관련 조항 3초 검색 & 타 공기업 사례 비교 요약표 5분 작성
4. **홍보자료 & 카드뉴스 & 안내문 만들기**: 사내 행사·캠페인 포스터 시각 이미지 및 게시판용 카드뉴스 문구 즉시 제작
5. **발표자료(PPT) 만들기 & 매뉴얼 양산**: 기안문 원문만 넣으면 발표 슬라이드·대본 생성 & 부서별 업무 인수인계서 표준화
6. **웹 업무포털 자동화하기 & 재입력 대행**: 엑셀 수치를 사내 ERP/전자결재 시스템에 일일이 복사·붙여넣기하던 클릭 노동을 AI 에이전트가 화면 직접 조작(Computer Use)으로 대행
7. **물품 주문 & 견적 비교 시키기**: 사무용품·비품 사양만 주면 최저가 비교 견적서 작성 ➔ 구매 품의서 초안 ➔ 구매 링크 정리 일괄 처리

## 🎬 모션 & Manim 영상

슬라이드 진입 연출은 `assets/deck-motion.js`(anime.js v3)가 담당합니다. `runtime.js`는 건드리지 않고 `body[data-current-slide]` 변화를 감지해 동작합니다.

| 구조 | 연출 |
|---|---|
| 히어로(챕터 간지) | 배경 이미지 켄번즈(20초 느린 확대) → 필 → 제목 단어 stagger → 부제 |
| 본문 슬라이드 | 키커 → 제목 단어 stagger → 부제 → 카드 stagger → 강조 카드 글로우 |
| `.versus` | 왼쪽 카드 → **VS** 배지 팝 → 오른쪽 카드 |
| `[data-flow]` (6·30·32) | 카드 위에 타임라인(선·점·화살표)을 그려 "세대 진화 / 단계" 를 시각화 |
| `[data-formula]` (8) | 카드 사이에 **+** 연산자 → 마지막에 **= 하네스** 결과 문장 |
| `[data-count-to="80"]` (20) | 숫자 카운트업 |
| `video` (7·12) | 진입 시 처음부터 자동 재생, 이탈 시 정지. 영상 클릭 또는 `↻ 다시 재생` 버튼 |

- `R` 키: 현재 슬라이드 연출 다시 재생 (대본 흐름에 맞춰 카드를 다시 등장시킬 때)
- 발표자 미리보기(`?preview=N`)와 `prefers-reduced-motion` 환경에서는 연출을 생략하고 최종 상태만 보여줍니다.
- 레이아웃/디자인 보정은 `assets/deck-v2.css`에 모아 두었습니다 (히어로 풀블리드, 가운데 정렬 그리드 폭 버그 수정, 카드 위계, VS 배지, 영상 박스 등).
