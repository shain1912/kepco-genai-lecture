## 🧭 강연 구성 (통합 스토리라인 39장)

단순한 프롬프트 작성을 넘어, **"무엇을 맡기고 무엇을 맡기지 않을 것인가(1부)"**를 정하고, **"말 대신 시스템과 스킬을 남기는 업무자동화(2부)"**로 나아가는 전일 과정입니다.

```
[오프닝 & 설문]
  01. 표지 (일러스트 히어로)
  02. 설문 ①: 지난주, AI에게 시킨 일은?
  03. 오늘의 로드맵: 두 가지 질문으로 풀어가는 여정
  04. 오늘 끝나면 들고 나갈 종이 한 장 (우리 팀 AI 판단 기준 4칸 시트)
  05. 오늘 여러분의 역할 (판단하는 사람)

[PART 1 · 생성형 AI 실무 활용: 무엇을 맡길 것인가]
  06. 문제 던지기: "써봤는데 별로던데요"
  07. 고칠 수 있는 것 vs 없는 것 (프롬프트 한계 vs 도메인 지식)
  08. 라이브 시연 ①: 순시 메모 원자료와 프롬프트 3종 비교
  09. 프롬프트 C의 비밀: 판단 기준을 문장으로 주는 법
  10. 핵심 메시지 ①: 차이를 만든 건 AI 성능이 아니라 내가 준 판단 기준이다
  11. 도메인 지식: AI가 발전해도 줄지 않는 판단의 층
  12. 라이브 시연 ②: 환각 (새벽 두 시의 설비 이상 보고)
  13. "전부 가짜입니다": 지어낸 조항과 시한의 실체
  14. 환각의 원리: Next-token prediction (확률적 문장 완성)
  15. 환각 대응 원칙: "맞아?"가 아니라 "어디를 보면 확인돼?"
  16. 라이브 시연 ③: 사내 보안과 개인정보 (민원 데이터 마스킹)
  17. Part 1 정리: 오늘 확인한 세 가지 판단 (AI가 답을 만들고 사람이 판단한다)

[PART 2 · 프롬프트의 종말: 에이전트 업무자동화]
  18. 전환 표지: 그런데 언제까지 매번 프롬프트로 주문만 할 것인가?
  19. 프롬프트의 한계: 창을 닫으면 사라지는 휘발성
  20. 개념 정의: 챗봇과 에이전트는 완전히 다르다
  21. 핵심 개념: 말 대신 남기는 것들 (3대 자산: 컨텍스트·스킬·MCP + CLI)
  22. 라이브 시연 ④: 같은 요청, 프롬프트 vs 스킬 파일(SKILL.md)
  23. 퀴즈 ②: 매주 반복하는 보고서를 AI에게 맡기려면?
  24. 비유로 이해하기: 남이 지은 SaaS 식당 vs 우리 집 로컬 주방
  25. 세 가지 차이: 데이터 위치(사내) · 도구 연결(MCP) · 자동화 지속성
  26. 3단계 진화 모델: 웹 챗봇 -> 터미널 도구 -> 로컬 에이전트
  27. 설문 ③ (주관식): SaaS로는 안 되는데 사람 손으로 하고 있는 일은?
  28. 라이브 시연 ⑤: 브라우저는 "남의 집" — Chrome 제어
  29. 라이브 시연 ⑥: Computer Use & 자가 치유(Self-healing 루프)
  30. 퀴즈 ④: 에이전트가 실패했을 때 한 일은?
  31. 라이브 시연 ⑦: 바이브코딩 — "만들어 줘"가 아니라 완성 사진을 먼저
  32. 일하는 방식: 완성 사진 · 합격 조건 3줄 · 샘플 검수
  33. 하네스 8단계: 주방 세팅, 루프 실행, 매뉴얼화

[PART 3 · 공기업 현실과 실행]
  34. 공기업 현실: 어디까지가 안전한 시작점인가 (망분리 3대 안전선)
  35. 부서별 첫 스킬 후보 3종 (주간보고 취합 · 민원 답변 초안 · 규정 개정 대조표)
  36. 지속성 3단계: 개인 스킬 -> 팀 매뉴얼 -> 전사 자산
  37. 설문 ④ (실행 다짐): 내일 당장 스킬로 만들고 싶은 내 업무는?
  38. 이번 주에 하실 것 세 개 (템플릿 채우기, 팀 회의 10분, 사내 지침 확인)
  39. 클로징 & Q&A: "AI에게 일터를 내주는 시대. 병목은 기술이 아니라 현장 지식입니다."
```

## ⌨️ 슬라이드 조작 단축키

| 키 | 기능 | 설명 |
|---|---|---|
| `←` `→` / `Space` | **이동** | 슬라이드 앞/뒤 전환 (프레젠터 리모컨 완벽 호환) |
| `S` | **발표자 모드** | 별도 팝업 창에 현재 슬라이드, 대본, 경과 타이머, 다음 슬라이드 미리보기 표시 |
| `O` | **전체보기 그리드** | 39장 전체 슬라이드를 한눈에 보고 원하는 곳으로 즉시 이동 |
| `T` | **테마 전환** | 한전 나이트(기본 다크) / 도쿄 나이트 / 블루프린트 / 비즈니스 클린 / 미니멀 화이트 |
| `F` | **전체화면** | 프레젠테이션 전체화면 전환 |
| `R` | **타이머 리셋** | 발표 타이머 초기화 |

## ⚠️ 교육용 자료 고지

슬라이드에 등장하는 **순시 메모, 사내 지침(○○사업소 설비이상 보고 지침), 고객 민원 데이터는 전부 교육용 가상 자료**입니다. 실재하는 한국전력공사의 규정·설비·고객 정보와 무관하며, 실무 판단의 근거로 사용할 수 없습니다.
