Section · 01 20분

프롬프트의 종말

왜 '프롬프트 잘 쓰기' 강의는 곧 사라지는가

개념 · 첫 번째 비유

챗봇과 에이전트는 다르다

챗봇은 창밖에서 레시피를 불러주는 사람,
에이전트는 주방에 직접 들어와 요리하는 사람.

그래서 에이전트는 손(설치)이 필요합니다. 여러분의 컴퓨터, 폴더, 브라우저에 들어와야 일을 할 수 있으니까요.

한전 업무 장면주간보고 취합 · 민원 답변 문안 · 엑셀 자료 정리 · 규정·지침 요약 · 회의록 → 조치사항
공기업 필수내부문서·고객 개인정보는 넣지 않기. 가명화·샘플 데이터로 시작.
보안 안내는 여기서 한 번, 4부에서 한 번 더. 지금은 가볍게.

프롬프트 = 주문 내용. 매번 새로 말해야 한다

말 대신 남기는 것들 — 3대 자산과 실행 도구

컨텍스트신입 인수인계 문서 — CLAUDE.md. 우리 부서 규칙을 벽에 붙여 둔다.
스킬업무 매뉴얼 파일 — 한 번 만들면 옆 부서에 그대로 넘겨준다.
MCP220V 콘센트 규격 — 어떤 도구든 같은 규격으로 꽂는다. 한전 분들이 가장 잘 아는 비유.
CLI키오스크 vs 카운터 직원 — 정해진 메뉴만 누르던 것에서, 말로 주문하는 것으로.
프롬프트는 휘발된다. 남는 것은 파일이다. 이 세 층위가 오늘 4부에서 다시 나온다.

Section · 02 25분

Agent vs SaaS

오늘의 중심. 빌려 쓰는 것과 데려다 쓰는 것

개념 · 두 번째 비유

남이 지은 식당, 우리 집 주방

SaaS = 남이 지은 식당.
메뉴판에 있는 것만 시킬 수 있다.

Agent = 우리 집 주방에 온 요리사.
재료·도구를 다 만지고, 없으면 만들어 쓴다.

번역기·요약기·챗봇 창은 전부 식당입니다. 편하지만, 한전의 양식과 규정은 메뉴판에 없습니다.

SaaS를 폄하하지 않는다. "메뉴판에 있으면 식당이 더 싸고 빠르다." 문제는 메뉴판에 없는 우리 일.

표 하나로 끝내는 차이

세 가지 질문만 던져 보세요

질문SaaS (식당)Agent (우리 주방)
누가 도구를 고르나?서비스 회사가 미리 정해 둔다에이전트가 상황 보고 고른다 · 없으면 만든다
실패하면 누가 재시도하나?사람이 다시 누른다로그를 보고 스스로 다시 한다
우리 회사 규정을 아나?모른다 · 알려줄 방법도 제한적인수인계 문서(CLAUDE.md)를 읽고 일한다
두 번째 줄이 오늘 시연의 핵심. 3부에서 일부러 실패시켜 보여줄 것이라고 예고.

Section · 03 35분

에이전트가 실제로 일하는 장면

Claude in Chrome · Computer Use · Claude Design

시연 ② · Claude in Chrome 10분

브라우저는 "남의 집". 에이전트가 거기까지 간다

  1. 사내 포털형 샘플 사이트에서 공지 30건을 읽는다
  2. 제목·부서·기한을 엑셀로 정리한다
  3. 기한이 3일 이내인 것만 골라서 요약한다
  4. 내가 한 일: 한 문장 말한 것뿐
탐색기 = 우리 집, 브라우저 = 남의 집. 이제 남의 집에서도 일한다.
실제 사내 포털은 절대 쓰지 않는다. 사전에 만든 가짜 포털 사이트 사용. 이 점을 청중에게도 말해 보안 감각을 심는다.

시연 ③ · Computer Use / Cowork 12분

일부러 실패시킨다 — 그리고 스스로 다시 한다

  1. 폴더 속 현장 점검 메모 수십 건(가명화 샘플)
  2. 취합 → 보고서 초안 → 엑셀 집계
  3. 중간에 양식이 깨진 파일 하나를 심어 둔다
  4. 에이전트가 로그(주방 CCTV)를 보고 원인을 찾아 재시도
이 장면이 SaaS와의 결정적 차이. 사람이 다시 누르지 않는다.
실패 장면에서 잠깐 멈추고 "지금 뭐가 일어났죠?"라고 묻는다. 청중이 로그를 눈으로 보게 한 뒤 재시도 장면을 보여준다. 퀴즈 ④의 정답이 여기서 나온다.

보안 담당 부서가 청중에 있을 수 있다. "스킬 파일에는 데이터가 없다"는 문장이 핵심 방어 논리.
